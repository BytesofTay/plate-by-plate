# Web prototype

- `app.html` is the source. It's written as a claude.ai artifact: page content without `<html>`/`<head>`/`<body>`, because claude.ai adds the skeleton when it publishes.
- `index.html` is generated by `npm run sync-prototype` from the repo root. It's a full standalone document; open it in any browser.

## Storage

- **On claude.ai** (published with the `db` and `user` capabilities), each viewer's log saves privately to their Claude account. The profile is at `data/users/<id>/profile` and sessions are at `data/users/<id>/profile/sessions/<sessionId>`.
- **Anywhere else**, `window.claude` doesn't exist, so the app falls back to localStorage (`pbp-local-v1`) and the header says "Saved on this device".

The in-progress workout draft always lives in localStorage (`pbp-drafts-v1`), so a page reload mid-workout doesn't lose sets.

## Editing

- Program and morning data sit between the `<generated:program>` markers, and the progression functions (`progress`, `plates`, `warmups`, `loadable`, `e1rm`, `weightStep`) between the `<generated:logic>` markers. Change them in `packages/core`, then run `npm run sync-prototype`.
- UI and styles live in `app.html` itself.
